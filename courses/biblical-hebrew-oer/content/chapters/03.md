# Unit 3 — Matres Lectionis

Some Hebrew consonant letters also help write long vowels. This unit explains the main consonant-vowel overlap and how position helps identify it.

## Summary

Waw, yod, and final he can function as matres lectionis. In this use, waw commonly accompanies û or ô, yod can accompany î or ê, and final he can accompany a vowel at the end of a word. A mater is not a vowel point; it is a consonant letter used as a spelling aid. If the same letter has its own vowel point or begins a syllable, it is more likely functioning as a consonant.

## Mater Lectionis Patterns

| Letter | Common vowel values | Common position |
| --- | --- | --- |
| ו | û, ô | medial or final |
| י | î, ê | medial or final |
| ה | â, ê, ô | word-final |
